# Homebrew tap for Multipaste

Install [Multipaste](https://github.com/NewdlDewdl/multipaste) — native macOS clipboard history and snippet expansion:

```sh
brew install --cask NewdlDewdl/multipaste/multipaste
```

Or, equivalently:

```sh
brew tap NewdlDewdl/multipaste
brew install --cask multipaste
```

Uninstall (keeps history and prefs):

```sh
brew uninstall --cask multipaste
```

Uninstall and wipe everything:

```sh
brew uninstall --cask --zap multipaste
```

The cask formula lives at [Casks/multipaste.rb](Casks/multipaste.rb).
